# Medicare - Doctor Landing Page

A modern, responsive healthcare website template designed for medical professionals, clinics, and healthcare institutions. This project features a clean design with professional aesthetics, interactive elements, and comprehensive functionality.

## 🌟 Features

### Design & Layout
- **Modern Hero Section** with doctor profile card and floating statistics
- **Responsive Grid Layouts** for services, doctors, and testimonials
- **Professional Color Scheme** with medical-themed gradients
- **Interactive Animations** and smooth scrolling effects
- **Mobile-First Design** with full responsive support

### Sections Included
1. **Navigation Bar** - Fixed header with smooth scroll navigation
2. **Hero Section** - Eye-catching banner with call-to-action buttons
3. **About Section** - Medical center information with feature highlights
4. **Services Section** - Comprehensive medical services grid
5. **Doctors Section** - Professional profiles with ratings and specialties
6. **Testimonials** - Patient reviews and feedback
7. **Contact Section** - Contact form and clinic information
8. **Footer** - Links, social media, and additional information

### Interactive Features
- **Appointment Booking Modal** - Complete booking system with form validation
- **Mobile Navigation Menu** - Hamburger menu for mobile devices
- **Smooth Animations** - Intersection Observer API for scroll animations
- **Contact Form** - Functional contact form with validation
- **Scroll-to-Top Button** - Easy navigation back to top
- **Counter Animations** - Animated statistics in hero section

## 🚀 Technologies Used

- **HTML5** - Semantic markup structure
- **CSS3** - Modern styling with Flexbox and Grid
- **JavaScript (ES6+)** - Interactive functionality and animations
- **Font Awesome** - Professional medical icons
- **Google Fonts** - Inter font family for clean typography

## 🛠️ Setup Instructions

1. **Clone or Download** the project files
2. **Open index.html** in your web browser
3. **No build process required** - pure HTML, CSS, and JavaScript

### For Development:
1. Use a local server (like Live Server in VS Code) for best experience
2. Modify colors, content, and images as needed
3. Test responsiveness across different devices

## 🔧 Customization Guide

### Changing Colors
Update the CSS custom properties in `styles.css`:
```css
:root {
  --primary-color: #2563eb;
  --secondary-color: #667eea;
  --accent-color: #fbbf24;
}
```

### Adding New Sections
1. Add HTML structure in `index.html`
2. Style the section in `styles.css`
3. Add any interactive functionality in `script.js`

### Modifying Content
- **Doctor Profiles**: Update images, names, and specialties in the doctors section
- **Services**: Modify service cards with your specific medical services
- **Contact Information**: Update phone, email, and address details
- **Testimonials**: Replace with real patient reviews

### Image Replacement
Replace Unsplash URLs with your own images:
- Doctor photos: Professional headshots
- Medical facility images: Your clinic/hospital photos
- Service icons: Can be replaced with custom medical icons
